## What I'm building
 
- 🗳️ **discourse-ballotage**: Discourse plugin for secret black/white-ball ballots. It records who voted, but not what they voted.
- 🔐 **online-ballotage**: the same idea as a standalone, self-hostable tool. Passwordless magic-link login, one-time voting links, and a data model where vote and person can't be linked.
## What I do for a living
 
Self-hosting, Docker, infrastructure as code, single sign-on, keeping AI agents on a short leash, ERP integrations and smart-home sensors. My rules of thumb:
 
1. If it can be automated, I automate it. If not, I at least write it down.
2. Configuration belongs in Git, not in my head.
3. Containers run on latest. Yes, I know. There is monitoring.
